# Codex Voice UI 状态

[English](./ui-states.md)

## 1. 空闲态

话筒窗口保持紧凑。话筒按钮使用简洁线性图标。Auto-send 作为明确选项显示。

## 2. 录音态

话筒按钮切换为录音状态。转写区域显示临时语音识别结果。

## 3. 确认态

用户可以编辑转写内容，并选择：

- 填入 Codex
- 复制
- 清空
- 在 Codex 中润色

## 4. 已填入

Codex Voice 辅助组件会尝试通过 macOS 辅助功能自动填入。如果失败，则把转写内容复制到剪贴板。

## 5. 错误态

错误应该可恢复，并且文案简短：

- 麦克风不可用。
- 语音识别不可用。
- Codex Voice 辅助组件不可用。
- 辅助功能填入失败，已复制到剪贴板。
